# Telegram Bot Project

## Stack

- Python 3.12
- aiogram 3
- SQLite
- yt-dlp
- Railway
- GitHub

## Important rules

- Не удаляй существующий функционал без моего разрешения.
- Не переписывай архитектуру без необходимости.
- Перед крупными изменениями сначала объясняй план.
- Не изменяй .env.
- Никогда не выводи BOT_TOKEN.
- Не храни секреты в исходном коде.
- Сохраняй совместимость с текущей архитектурой.
- После изменения кода проверяй его на ошибки.
- Не делай git push без моего явного разрешения.

## Workflow

Перед реализацией сложной задачи:

1. Изучи существующий код.
2. Найди связанные файлы.
3. Объясни причину проблемы.
4. Предложи план.
5. После моего подтверждения внеси изменения.
6. Проверь результат.
7. Покажи список изменённых файлов.
8. Покажи, что именно было проверено.
